# Week 1 — 3D Desk Setup Mini Project

## Objective
Create a complete desk setup scene in 3D containing:

- Desk
- Monitor
- Keyboard
- Mouse and mouse pad
- Desk lamp
- Coffee mug
- Basic materials and colors
- 3-point lighting
- Final render at **1920 × 1080**

## Deliverables

- `desk_setup.py` — procedural Blender scene generator.
- `week1_desk_setup.blend` — generated by running the script in Blender.
- `render/week1_desk_setup.png` — generated 1920×1080 final render.

## How to Run

1. Install Blender 3.x or newer.
2. Open Blender.
3. Open `desk_setup.py` in the Scripting workspace.
4. Run the script.
5. The script builds all modeled objects, materials, lights and camera automatically.
6. It saves the Blender scene as `week1_desk_setup.blend`.
7. It renders the final image to `render/week1_desk_setup.png`.

## Modeling Breakdown

### Desk
Walnut desktop, four legs and a cable tray.

### Monitor
Monitor body, screen, stand and stand base. The screen uses a blue accent material for visual contrast.

### Keyboard
Keyboard body with individually modeled keys and a spacebar.

### Mouse
Ergonomic mouse modeled from a UV sphere with a center accent strip, placed on a mouse pad.

### Lamp
Metal base and pole, tapered shade and bulb, plus a warm practical point light.

### Coffee Mug
Ceramic cylindrical mug, coffee surface and torus-style handle.

## Materials

The scene uses separate procedural materials for walnut wood, matte black, dark plastic, ceramic white, brushed metal, blue accent, coffee and the background wall.

## Lighting

A classic 3-point setup is included:

- **Key Light:** warm, high-intensity area light from camera-left.
- **Fill Light:** cooler, lower-intensity area light from camera-right.
- **Rim Light:** rear area light separating the objects from the background.

An additional warm point light provides the desk-lamp glow.

## Camera & Render

- Resolution: **1920 × 1080**
- Aspect ratio: **16:9**
- Engine: **EEVEE Next**
- Output: PNG
- Camera: three-quarter front view of the complete desk
