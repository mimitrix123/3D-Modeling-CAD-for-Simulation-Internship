# Week 3 Render Outputs

Run `../cantilever_fea.py` inside Blender to generate:

- `cantilever_fea.png` — presentation view of the loaded beam and stress heat map.
- `cantilever_deformation.png` — final-frame deformation visualization.
- `../cantilever_fea.blend` — Blender scene containing the model, load/support markers, heat-map segments, animation and cameras.

The deformation is visually exaggerated for readability. The engineering reference value is the analytical 1.6875 mm tip displacement documented in `../report/fea_report.md`.
