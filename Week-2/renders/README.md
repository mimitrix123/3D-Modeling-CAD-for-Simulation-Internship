# Week 2 Render Outputs

Run `../gear_train_assembly.py` from Blender to generate:

- `gear_train_assembly.png` — assembled three-gear train render.
- `gear_train_exploded.png` — exploded-view render.

The script also saves `../gear_train_assembly.blend`.

These binary outputs are generated by Blender and are intentionally not fabricated in this repository until the script is executed in Blender.
