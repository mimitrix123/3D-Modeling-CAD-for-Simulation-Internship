# Week 2 — Functional 3-Gear Mechanical Assembly

## Objective
Design a functional mechanical assembly with 3+ parts, constraints/joints, an exploded view, dimensioned technical drawing, and a final render setup.

## Assembly
- Fixed base plate: 220 × 100 × 10 mm
- Input gear: 20 teeth, module 2, pitch diameter 40 mm, nominal outside diameter ≈44 mm
- Idler gear: 30 teeth, module 2, pitch diameter 60 mm, nominal outside diameter ≈64 mm
- Output gear: 40 teeth, module 2, pitch diameter 80 mm, nominal outside diameter ≈84 mm
- Three shafts: Ø12 mm
- Gear thickness: 12 mm

## Functional relationships
- Gear 1 → Gear 2 → Gear 3
- Center distance G1–G2: 50 mm
- Center distance G2–G3: 70 mm
- Gear 2 rotates at `-(20/30)` of Gear 1.
- Gear 3 rotates at `-(30/40)` of Gear 2, giving Gear 3 half the speed of Gear 1 and the same final direction.
- Base is fixed; each gear is revolute about its shaft axis.

## Deliverables
- `gear_train_assembly.py`: Blender procedural model, constraints/joint metadata, drivers, animation, exploded configuration, cameras, lights and render setup.
- `drawings/technical_drawing.svg`: dimensioned drawing reference with orthographic views and BOM.
- `drawings/technical_drawing_notes.md`: drawing and manufacturing notes.
- `renders/README.md`: render instructions and expected output files.

## Running
Open Blender, switch to the Scripting workspace, open `gear_train_assembly.py`, and Run Script. The script saves the assembly `.blend` file and renders assembly/exploded PNGs relative to the script location.

> Note: the repository contains the generator script and drawing reference. The `.blend` and PNG binaries are generated by running the script in Blender.
